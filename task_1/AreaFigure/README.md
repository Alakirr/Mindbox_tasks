AreaFigure Library
AreaFigure — это библиотека на Python для вычисления площадей различных геометрических фигур, таких как круги и треугольники. Библиотека предоставляет простой и удобный интерфейс для работы с фигурами и вычисления их площадей.

Особенности:
Поддерживаемые фигуры: Круги и треугольники.
Масштабируемость: простота добавления дополнительных фигур.
Проверка свойств: возможность проверки, является ли треугольник прямоугольным.
Тестируемость: полная поддержка юнит-тестов для уверенности в правильности работы.
Структура библиотеки:
calculate_areas.py: определение классов фигур (Circle, Triangle) и их методов.
tests: набор юнит-тестов для проверки корректности вычислений.
